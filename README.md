# One-Line Laugh Sprint

One original funny line about everyday life: the elevator has been "out of order" for 8 months, and the punchline is what that did to the narrator's calves. `main.py` writes the line to `/output/entry.txt`, gated to 1–200 characters and verified byte-for-byte after writing.
